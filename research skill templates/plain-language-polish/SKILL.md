# Plain-Language Polish

Ask the user to paste or attach the project summary if it isn't already in the conversation. Then take the heavily jargon-filled text and rewrite it to:

- Retain technical accuracy.
- Improve readability and engagement for a diverse evaluation board (not every reviewer shares the applicant's specialism).

Show the rewritten version, and note any term you simplified that the user may want to double-check for precision.
